# timothee-consulting.fr

Site portfolio + CMS maison de Timothée Consulting.

- **Stack** : PHP 8.4, Symfony 7.4 LTS (installé via Symfony CLI), MariaDB, Redis, Twig, Symfony UX (Turbo, Stimulus, Live Components), assets TypeScript via esbuild.
- **Architecture** : DDD event-driven (SOLID, KISS, DRY, patterns Constant et Décorateur) — voir `aidd_docs/memory/`.
- **Plan de développement** : `aidd_docs/tasks/`.
- **Licence** : MIT (`LICENSE`).

Ce dépôt est public pour la transparence, mais le projet n'accepte pas de contributions externes pour l'instant.
